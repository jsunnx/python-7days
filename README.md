# python-7days

七天把一件事做完。

## 七天任务

| 天 | 内容 | 文件 |
|----|------|------|
| 1 | 环境 + 第一次 push | `hello.py` |
| 2 | 今日记录器 | `day2_record.py` |
| 3 | 批量重命名 | `day3_rename.py` |
| 4 | JSON 清单 CLI | `day4_todo.py` |
| 5 | 函数化 + 日报导出 | `day5_export.py` |
| 6 | 拉公开 API | `day6_api.py` |
| 7 | README + v0.1.0 | 此文件 |

## 怎么跑

```bash
python hello.py
```

## 规则

每天 45 分钟，一个 commit，七天不换方向。
